# กฎคำอธิบาย (ใช้กับทุกหน้า)

- ข้อความอธิบายทุกจุดในแอปต้องดึงจากคลัง `lib/interp_lib_th.json` ด้วยคีย์ ห้ามเขียนข้อความแยกเฉพาะหน้า
- ข้อความในไฟล์ดีไซน์ (`design/*.dc.html`) เป็น **ตัวอย่าง** แสดงตำแหน่งและความยาวโดยประมาณ — ตอนทำจริงแทนด้วยข้อความจากคลัง
- ถ้าคลังไม่มีคีย์ที่ต้องใช้ ให้เพิ่มใน `lib/gen2.py` (สร้างแบบประกอบจาก `data.py`/`pairs.py`) แล้วรันใหม่ ไม่เขียนข้อความลอยในโค้ด UI
- ตรวจแก่นความหมายกับคำอธิบายของ astro-seek ด้วย 3 ชาร์ตอ้างอิง: 5 ส.ค. 2542 20:33 เพชรบุรี · 31 พ.ค. 2543 13:52 กรุงเทพฯ · 18 มี.ค. 2547 09:26 นนทบุรี — ตรงหรือใกล้เคียง = ผ่าน (ผลรอบแรก 87/87 ดู 07)
- ห้ามคัดลอกข้อความตีความของ astro-seek (ลิขสิทธิ์) ใช้เทียบแก่นความหมายเท่านั้น

## โครงสร้างคีย์ของคลัง (lib/interp_lib_th.json)
รหัสดาว: S อาทิตย์ · M จันทร์ · m พุธ · V ศุกร์ · a อังคาร · J พฤหัสบดี · s เสาร์ · U ยูเรนัส · N เนปจูน · P พลูโต · n โหนดเหนือ · L ลิลิธ · c ไครอน · A ลัคนา · C กลางฟ้า
รหัสมุม: c กุม · x โยค · q ฉาก · t ตรีโกณ · o เล็ง · ราศี 0–11 (เมษ→มีน) · เรือน 1–12

| หมวด | คีย์ | ใช้ที่หน้า |
|---|---|---|
| planet_sign | `{ดาว}{ราศี}` เช่น `S4` | ชาร์ตของฉัน, Sheet |
| planet_house | `{ดาว}{เรือน}` เช่น `S6` | ชาร์ตของฉัน, Sheet |
| aspect | `{ดาว}{มุม}{ดาว}` (ลำดับตามรายการดาว) เช่น `Sqa` | มุมดาวทั้งหมด, ชาร์ตของฉัน |
| transit | `{ดาวจร}{มุม}{ดาวเดิม}` เช่น `UqV` | Transit, ปฏิทินดวงส่วนตัว, ไทม์ไลน์, วันนี้ |
| transit_house | `{ดาวจร}{เรือน}` | Transit, วันนี้ |
| synastry | `{ดาวของA}{มุม}{ดาวของB}` | เปรียบเทียบ |
| eclipse | `sun{เรือน}` `moon{เรือน}` `new{เรือน}` `full{เรือน}` `hit{ดาว}` `level1-3` | อุปราคา, จันทร์ดับจันทร์เต็ม |
| moon | `new` … `waning_crescent`, `voc`, `sign{0-11}` | ปฏิทินดวงจันทร์, วันนี้ |
| retrograde | `{ดาว}`, `pre`, `post` | ช่วงดาวถอยหลัง |
| return | `sr_asc{ราศี}` `sr_sun{เรือน}` `lr_asc{ราศี}` `lr_moon{เรือน}` `pm_sign{ราศี}` `pm_house{เรือน}` `ps_sign{ราศี}` (อาทิตย์โปรเกรส) | ดวงรอบปี, ดวงรอบเดือน, ตัวตนเติบโต |
| direction | `{pr|sa|pd}{ดาว}{มุม}{ดาว}` | ตัวตนเติบโต (3 แท็บ) |
| cycle | `{ดาว}_rule`, `{ดาว}_{return|sq1|opp|sq2}`, `venus_*` | รอบโคจรของดาวเคราะห์, วงโคจรดาวศุกร์ |
| numerology | `life{n}` `year{n}` `month{n}` | เลขศาสตร์ |
| electional | `new` `waxing` `waning` `moon_benefic` … `voc` | หาฤกษ์ |
| shape | `bundle` `bowl` `bucket` `locomotive` `seesaw` `splash` | ชาร์ตของฉัน · รูปแบบชาร์ต (ผู้ใช้ขอ 6 พ.ย. 2569) |

ข้อความ "?" (คืออะไร · ใช้ดู · ทำไมสำคัญ) ของแต่ละหน้า ใช้ตามที่อยู่ในไฟล์ดีไซน์ได้เลย (เป็นข้อความ UI ไม่ใช่คำตีความ)
