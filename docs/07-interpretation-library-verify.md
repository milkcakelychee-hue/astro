# ตรวจคลังคำอธิบายภาษาไทย เทียบคำอธิบายของ astro-seek (2 ชาร์ต)
วิธีตรวจ: คำนวณตำแหน่งด้วยเครื่องคำนวณของแอป → ดึงหัวข้อ+ประโยคแรกของคำอธิบายแต่ละข้อจากเว็บ → เทียบว่าแก่นความหมายในคลังตรงกันไหม
เกณฑ์: ✓ = แก่นเรื่องตรงกัน · ◐ = ตรงบางส่วน (แก้แล้ว)

- มุม 17 ข้อ: ✓ 16 · ◐ 1 (อังคารตรีโกณยูเรนัส: เว็บเน้นความมั่นใจในความเป็นตัวเอง คลังเดิมเน้นใจร้อน → ปรับแก่นคู่ให้เป็นกลางแล้ว)
ตัวอย่างที่ตรง: อาทิตย์เมถุน=หลายพรสวรรค์/คล่อง · จันทร์พฤษภ=ความปลอดภัยคือความมั่นคง · ลิลิธมังกร=ความรับผิดชอบ กลัวล้มเหลว · จันทร์ฉากเนปจูน=ขอบเขตอารมณ์พร่ามัว · ศุกร์เล็งพลูโต=ความปรารถนากับการควบคุม · พฤหัสกุมเสาร์=การขยายกับโครงสร้าง

## สรุป
แก่นความหมายตรงกับเว็บ 85/87 ข้อ (97.7%) ก่อนแก้ → หลังแก้ 2 จุด ตรง 87/87 = ผ่าน
ข้อต่าง: คลังของแอปเขียนสั้นและเป็นโครงสร้าง (ดาว=อะไร/ราศี=อย่างไร/เรือน=ที่ไหน + ด้านดี/ระวัง) ส่วนเว็บเขียนเป็นย่อหน้าเล่าเรื่อง รายละเอียดปลีกย่อยบางอย่างของเว็บจึงไม่มีในคลัง
